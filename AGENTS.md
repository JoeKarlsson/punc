# Punc

TypeScript library and CLI that extracts punctuation from text files, counts it, reports words per sentence, and renders punctuation-only PDF visualizations (`src/`, tests in `tests/`).

Run `npm run check` (type check, lint, markdown lint, tests) before committing. For changes to the site, also run `npm run test:e2e` (Playwright, builds and serves the site itself).

The static site is in `site/` (built by `npm run site:build` into `site-dist/`, deployed to GitHub Pages on push to `main`). Its design follows joekarlsson.com: a photocopied punk zine look, black ground, hot pink `#ff4fd8`, Anton for poster type, Fraunces for reading and for the marks. Shelf covers are Gutenberg covers dithered to pink and black in the browser (`site/src/dither.ts`). `site/catalog.json` and `site/covers/` are generated by `site/scripts/fetch-books.mjs`; edit its title, author and year overrides rather than the JSON. Book texts never go in git or on the site: the fetcher writes them to the gitignored `texts/`, and `site/scripts/analyze-books.mjs` analyzes each once into `site/marks/<slug>.json.gz` (marks, counts, measures and the Pages view, no words) plus `site/scanner-openings.json` (the front page scanner's public-domain openings). The build and the book pages read only those. `npm run shelf:update` is the whole bulk import (fetch the top 2000, analyze, build, render each book's share card into `site/share/` and shrink it to a 256-color PNG with pngquant (`brew install pngquant`), check, commit and push); the build warns about any book without a share card. The built site is about 340 MB (2,456 books) of GitHub Pages' 1 GB limit. A bigger shelf can change the numbers page: if e2e flags a section's held height, update its `--section-height` in `site/styles.css`, and regenerate the map screenshots with `npm run test:visual:update`.
