About

Artist statement

What does a book look like without words? Punc strips text down to its punctuation skeleton and visualizes the patterns left behind.

How it works

Punc reads a text file, drops every letter and number, and keeps the marks: periods, commas, semicolons, dashes, quotes, brackets and about a hundred other symbols. Curly quotes and long dashes count as their plain versions.

Everything happens in your browser. A file you open on the read page is never uploaded anywhere.

The books on the shelf are public domain texts from Project Gutenberg, with Gutenberg's license header and footer removed.

Punc is also a TypeScript library and command line tool that makes PDF, SVG and PNG versions of the same pictures: npm install punc.

Credits

Punc started in 2016 after Adam J. Calhoun's essay Punctuation in novels, which was itself inspired by Nicholas Rougeux's Between the Words.
